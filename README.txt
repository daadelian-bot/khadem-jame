سامانه جامع مدیریت خدام — نسخه ۵۳

نصب/به‌روزرسانی:
1) از Supabase نسخه پشتیبان تهیه کنید.
2) فایل SUPABASE_V53_MIGRATION.sql را در Supabase > SQL Editor اجرا کنید. این فایل جدول تنظیمات رابط کاربری را به صورت افزایشی می‌سازد.
3) اگر مهاجرت نسخه ۵۲ را قبلاً اجرا نکرده‌اید، ابتدا SUPABASE_V52_MIGRATION.sql را اجرا کنید. اگر نسخه‌های پایه هم اجرا نشده‌اند، ترتیب مهاجرت‌های قبلی را مطابق README همان نسخه‌ها رعایت کنید.
4) فایل index.html و logo.png را در مخزن GitHub جایگزین و commit کنید تا Netlify منتشر کند.
5) وارد سامانه شوید و از منوی «راهنمای سامانه» راهنمای داخل برنامه را بخوانید.
6) برای تغییر عنوان سامانه، عنوان مرکز عملیات، نام نمایشی مدیر اصلی و نام منوها: مدیریت سامانه > عنوان‌ها و منوها. فقط حساب دارای profiles.role='admin' می‌تواند ذخیره کند.
7) در همان صفحه می‌توان منوی سفارشی اضافه یا حذف کرد. این گزینه منو و صفحه پایه می‌سازد؛ عملیات اختصاصی آن صفحه باید جداگانه توسعه داده شود.

توضیح سرفصل مالی:
اگر در فهرست سرفصل مالی نوشته «سرفصل‌ها دریافت نشدند»، مهاجرت V52 و سرفصل‌های جدول finance_accounts باید در پایگاه داده وجود داشته باشند؛ پس از اجرای موفق SQL صفحه را تازه‌سازی کنید. اگر باز هم خطا بود متن خطای واقعی را بررسی کنید.

مهم: کد از نظر نحو JavaScript بررسی می‌شود، اما اتصال زنده و سیاست‌های RLS پروژه شما از اینجا آزمایش نشده است. پیش از کار واقعی از داده‌ها پشتیبان بگیرید.
