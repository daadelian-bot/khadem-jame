# راهنمای نصب‌پذیری وب (PWA)

این بسته شامل `manifest.webmanifest` و `service-worker.js` است. برای ثبت Service Worker، سایت باید از HTTPS اجرا شود؛ GitHub Pages این شرط را برآورده می‌کند.

## انتشار
1. فایل‌های `index.html`، `manifest.webmanifest` و `service-worker.js` را در ریشه شاخه `main` قرار دهید.
2. `logo.png` فعلی را حفظ کنید؛ manifest به همین مسیر اشاره می‌کند.
3. پس از انتشار، سایت را باز کنید و در صورت مشاهده نسخه قدیمی، داده‌های سایت/کش را پاک کنید یا در پنجره خصوصی آزمایش کنید.

Service Worker فقط پوسته ثابت سایت را کش می‌کند و نباید درخواست‌های Supabase را کش کند. حالت آفلاین به معنی کارکرد آفلاین ورود یا عملیات پایگاه داده نیست.
