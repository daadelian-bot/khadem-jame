# سامانه جامع مدیریت خادمین — فایل‌های ۱۳۳ تا ۱۳۶

- فایل شماره ۱۳۳: `manifest.webmanifest` — مشخصات نصب‌پذیری PWA
- فایل شماره ۱۳۴: `service-worker.js` — کش پوسته برنامه
- فایل شماره ۱۳۵: `index.html` — صفحه ورودی
- فایل شماره ۱۳۶: `README-PWA.md` — این راهنما

## نصب در مخزن GitHub
این فایل‌ها را در ریشه مخزن `daadelian-bot/khadem-jame` و شاخه `main` قرار دهید. فایل `index.html` فعلی باید با نسخه شماره ۱۳۵ جایگزین شود؛ دو فایل manifest و service-worker را به‌صورت فایل جدید بسازید. `app.js` و `logo.png` را نگه دارید.

## بررسی پس از انتشار
1. آدرس https://daadelian-bot.github.io/khadem-jame/ را باز کنید.
2. ورود و بارگذاری داده‌ها را آزمایش کنید.
3. گزینه نصب/افزودن به صفحه اصلی را در مرورگرهای پشتیبانی‌شده بررسی کنید.
4. اگر صفحه سفید شد یا ورود/داده‌ها خطا داد، متن خطا را بفرستید.

توجه: فایل‌های PWA تضمین نمی‌کنند که تمام قابلیت‌ها آفلاین باشند یا برنامه بدون خطا روی همه دستگاه‌ها اجرا شود. سازگاری رابط با schema واقعی Supabase باید با آزمایش زنده تأیید شود.
