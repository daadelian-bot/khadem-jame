# سامانه جامع خادمین مجموعة السیدة زینب سلام الله علیها

## بستهٔ اصلاحات نسخه ۱۰۴
- فایل اصلی برنامه: `index.html` — نسخه ۱۰۴
- نصب‌پذیری وب: `manifest.webmanifest`
- پوسته آفلاین: `service-worker.js` — کش پوسته نسخه ۱۳۹
- گزارش جزئیات و موارد باقی‌مانده: `RELEASE_READINESS.md`
- لوگو: فایل `logo.png` موجود در ریشه مخزن باید حفظ شود؛ در این بسته جایگزین نشده است.

## نکته معماری
کد اصلی فعلی در `index.html` قرار دارد. فایل‌های `app.js` و `styles.css` موجود در مخزن در این ورودی HTML بارگذاری نمی‌شوند. آن‌ها را حذف یا با این نسخه ادغام نکنید تا زمانی که مهاجرت معماری و آزمون کامل انجام شود.

## بارگذاری دستی در GitHub
1. از مخزن فعلی نسخه پشتیبان بگیرید یا پیش از جایگزینی، فایل فعلی `index.html` را نگه دارید.
2. محتوای پوشه `release-package` را باز کنید.
3. در ریشه شاخه `main` فقط فایل‌های `index.html`، `service-worker.js` و `manifest.webmanifest` را جایگزین کنید. فایل‌های راهنما اختیاری‌اند.
4. **`logo.png` و فایل‌های دیگر مخزن را حذف یا جایگزین نکنید.**
5. تغییرات را commit کنید و صبر کنید GitHub Pages تکمیل انتشار را اعلام کند.
6. سایت را در پنجره خصوصی یا پس از پاک‌سازی داده‌های سایت باز کنید؛ سپس ورود، پرونده خادم، سوابق خدمت و مالی، درخواست‌های عضویت، منوها و تنظیمات را با حساب‌های آزمایشی بررسی کنید.

## هشدار امنیتی
کلید عمومی مرورگر مجوز دسترسی محسوب نمی‌شود. امنیت واقعی باید با احراز هویت، سیاست‌های RLS و کنترل سمت سرور اعمال شود. هرگز کلید `service_role` یا اسرار سرور را در `index.html` قرار ندهید.

این بسته به‌خودی‌خود APK/EXE/IPA تولید نمی‌کند. ابتدا باید نسخه وب و دسترسی‌های سمت سرور با داده‌های آزمایشی تأیید شوند.
