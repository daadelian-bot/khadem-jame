# راهنمای بازیابی رمز مدیر اصلی — نسخهٔ آزمایشی ۱۴۳

## روش عادی بازیابی
1. صفحهٔ ورود نسخهٔ ۱۴۳، دکمهٔ «راهنمای فراموشی رمز» را دارد.
2. ایمیل حساب مدیر اصلی را وارد کنید؛ درخواست به Auth پروژهٔ جدید `khadem-jame-next` ارسال می‌شود.
3. پیوند ایمیل باید به آدرس دقیق سایت بازگردد:
   `https://daadelian-bot.github.io/khadem-jame/`
4. پس از بازشدن پیوند، صفحه باید حالت «بازیابی امن رمز عبور» را نشان دهد. رمز جدید حداقل ۱۲ نویسه است و باید دوبار یکسان وارد شود.
5. پس از ذخیره، با رمز جدید از صفحهٔ ورود وارد شوید.

## تنظیمات لازم در داشبورد Supabase
- پروژهٔ درست: `khadem-jame-next` (ref: `ojmbhfubdpszxbqlbqqf`).
- در Authentication → URL Configuration، آدرس دقیق بالا را به Redirect URLs اضافه کنید و Site URL را نیز روی همین دامنه بگذارید.
- در Authentication → Email / SMTP، ارسال ایمیل واقعی را بررسی و یک SMTP قابل‌اعتماد تنظیم کنید. درخواست موفق API به‌تنهایی تضمین نمی‌کند ایمیل واقعاً تحویل شده باشد.
- تنظیمات قالب Recovery باید از پیوند تأیید Supabase استفاده کند، معمولاً `{{ .ConfirmationURL }}`.
- در Authentication → Security، قابلیت جلوگیری از رمزهای لو رفته را فعال کنید؛ Security Advisor در آخرین بررسی آن را خاموش گزارش کرد.

## جلوگیری از بن‌بست
- حداقل یک مالک/مسئول دومِ مورداعتماد باید به سازمان Supabase دسترسی مالکانه داشته باشد تا در صورت از دست رفتن دسترسی ایمیل یا خرابی تنظیمات Auth، بتواند از داشبورد Supabase حساب را بازیابی کند.
- روش اضطراری رسمی، استفاده از داشبورد مالک پروژه و بازنشانی حساب Auth است؛ رمز سرویس، service-role key یا رمز مدیر را در فایل HTML، GitHub، جدول عمومی یا پیام چت ذخیره نکنید.
- بازیابی ایمیل، رمز قبلی را لازم ندارد و به نشست فعلی مدیر وابسته نیست. پیوند بازیابی کوتاه‌عمر و یک‌بارمصرف است.
- اگر ایمیل مدیر در دسترس نباشد و هیچ مالک دوم به پروژه دسترسی نداشته باشد، نباید یک endpoint عمومی برای تغییر رمز مدیر ساخته شود؛ این کار هر مهاجم را قادر به تصاحب حساب مدیر می‌کند.

## وضعیت فعلی
فایل آزمایشی `index-auth-recovery-v143.html` به صورت محلی ساخته و ۳۵ بلوک JavaScript آن از نظر نحوی بررسی شده‌اند. این فایل هنوز در GitHub Pages منتشر نشده است. تنظیمات Redirect URLs و SMTP هم از طریق ابزارهای در دسترس این جلسه قابل تغییر نبودند و باید در داشبورد بررسی شوند. قبل از انتشار باید پیوند بازیابی واقعی با ایمیل مدیر آزمایش شود.
