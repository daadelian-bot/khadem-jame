## وضعیت و محدودیت‌ها
- پروژه جدید `khadem-jame-next` اکنون ۳۸ جدول عمومی دارد؛ همهٔ جدول‌های عمومی بررسی‌شده RLS فعال دارند. فقط یک ردیف پروفایل مدیر در این پروژه وجود دارد؛ اطلاعات خادمین و مالی از پروژه قدیمی کپی نشده‌اند.
- در پروژه جدید، ۹ مهاجرت در تاریخچه Supabase ثبت شده است. دو مهاجرت سازگاری در بالا با نسخه‌های ثبت‌شده هم‌نام‌سازی شده‌اند. فایل baseline یک snapshot بازسازی است و در پروژه زنده اجرا نشده؛ برای یک پایگاه تازه است.
- متن دقیق هفت مهاجرت اولیه از مخزن بازیابی نشد؛ baseline ساختار زنده فعلی را بازسازی می‌کند، نه اینکه وانمود کند متن اصلی آن هفت فایل بازیابی شده است.
- پروژه قدیمی `khadem-jame` و داده‌های واقعی آن دست‌نخورده مانده‌اند.
- هیچ سیاستی برای آزادسازی اطلاعات مالی یا هویتی به نقش `anon` اضافه نشده است. حذف صفحه ورود، مجوزهای Supabase را تغییر نمی‌دهد.
- فایل `index.html` سایت هنوز در GitHub Pages منتشر/جایگزین نشده است. نسخه آزمایشی بازشدن بدون صفحه ورود به‌صورت فایل جداگانه آماده شده و هشدار می‌دهد که بخش‌های نیازمند نشست احراز هویت ممکن است داده بارگذاری نکنند.
- پیش از اتصال نسخه سایت به داده‌های واقعی، باید سیاست‌های RLS برای مدل دسترسی نهایی و ستون‌های مورد انتظار کلاینت/عملیات هر ماژول یکپارچه و آزمون شوند.
