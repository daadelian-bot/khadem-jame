سامانه جامع خادمین — افزودن مدیریت شهریه خادمین

فایل‌ها:
- index.html: رابط وب نسخه ۱۳۱، شامل بخش «امور مالی ← شهریه خادمین»
- service-worker.js: پوسته آفلاین با نام کش جدید برای جلوگیری از نمایش فایل قدیمی
- khadem-jame-tuition-migration.sql: مهاجرت SQL برای ساخت جدول‌های شهریه و سیاست‌های دسترسی

وضعیت Supabase:
مهاجرت شهریه مستقیماً روی پروژه Supabase اجرا شده و بررسی شده است. یک ردیف تنظیم نرخ اولیه با ۱۰۰٬۰۰۰ تومان در ۶ ماه اول و ۲۰۰٬۰۰۰ تومان از ماه هفتم به بعد وجود دارد. جدول‌های شهریه فعال هستند و RLS روشن است. هنوز هیچ سررسید یا پرداختی ساخته نشده است.

قواعد:
- ماه عضویت شهریه ندارد؛ اولین سررسید ماه بعد از تاریخ عضویت است.
- ۶ سررسید نخست از نرخ اول استفاده می‌کنند؛ از سررسید هفتم به بعد نرخ دوم.
- محاسبه شهریه سررسیدهای موجود را بازنویسی نمی‌کند؛ نرخ جدید فقط روی سررسیدهای تازه اعمال می‌شود.
- مبلغ‌های فرم به تومان هستند؛ هنگام ثبت پرداخت، معادل ریالی (تومان × ۱۰) در finance_transactions ثبت می‌شود و پرداخت با پرونده خادم مرتبط می‌ماند.
- فقط حساب فعال با نقش admin یا manager به جداول شهریه دسترسی دارد.

انتشار:
۱) در مخزن GitHub، شاخه main را باز کنید.
۲) فایل index.html را با فایل همین بسته جایگزین کنید.
۳) فایل service-worker.js را هم جایگزین کنید.
۴) Commit changes بزنید و انتشار را در GitHub Actions / Cloudflare بررسی کنید.
۵) سایت را در پنجره ناشناس باز کنید و وارد «امور مالی ← شهریه خادمین» شوید.

این بسته هنوز به مخزن GitHub یا سایت زنده منتشر نشده است. برای امنیت، کلید service_role یا کلید مخفی را در فایل HTML قرار ندهید.
