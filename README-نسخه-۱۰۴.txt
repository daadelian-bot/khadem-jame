# سامانه جامع خادمین مجموعة السیدة زینب سلام الله علیها

## بستهٔ اصلاح‌شدهٔ نسخهٔ برنامه ۱۰۴
- نسخهٔ قابل‌نمایش برنامه: ۱۰۴
- شمارهٔ مرحلهٔ فایل حفظ شده: ۱۳۷ (این شماره نسخهٔ برنامه نیست)
- فایل اصلی: `index.html`
- فایل پوستهٔ نصب‌پذیر: `service-worker.js`
- تنظیمات نصب‌پذیری: `manifest.webmanifest`

## اصلاحات این بسته
- برچسب پایین صفحه از «مرحله فایل ۱۳۷ · نسخه برنامه ۹۵» به «مرحله فایل ۱۳۷ · نسخه برنامه ۱۰۴» اصلاح شد.
- تابع بررسی مدیر به `window.admin` متصل شد تا توابع سراسری مدیریت کاربران/درخواست‌ها بتوانند به آن دسترسی داشته باشند.
- هیچ مهاجرت، جدول، رکورد، کلید یا سیاستی در Supabase تغییر داده نشده است.

## نصب در GitHub
1. در مخزن `daadelian-bot/khadem-jame` و شاخه `main` از `index.html` فعلی پشتیبان بگیرید.
2. فایل‌های `index.html`، `service-worker.js` و `manifest.webmanifest` این بسته را در ریشهٔ مخزن جایگزین کنید.
3. `logo.png` و تمام فایل‌های دیگر را حفظ کنید؛ حذف یا جایگزینی آن‌ها لازم نیست.
4. commit کنید و پس از انتشار، سایت را در پنجرهٔ ناشناس باز کنید.
5. ابتدا تأیید کنید برچسب «مرحله فایل ۱۳۷ · نسخه برنامه ۱۰۴» نمایش داده شود؛ سپس مدیریت کاربران را آزمایش کنید.

این بسته تضمین نمی‌کند خطای زندهٔ Supabase رفع شده است؛ اگر پس از اصلاح محدودهٔ دسترسی تابع مدیر همچنان خطا وجود داشت، باید پاسخ API و مجوزهای فعلی فقط‌خواندنی بررسی شوند.
